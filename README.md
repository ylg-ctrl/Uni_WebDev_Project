# Wheels on Fire – Web Development Project

A multi-page website created for **Wheels on Fire** (curated by John O’Reilly).

## 📁 Project Structure

* `index.html` – Homepage featuring the company slogan and "Car of the Week".
* `collection.html` – Vehicle showroom presenting available garage inventory.
* `about.html` – Story, background, standards, and values of the dealership.
* `car3.jpg` – High-resolution showcase vehicle asset.
* `copyright.txt` – Photo attribution reference.

## 🛠️ Built With

* Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`)
* Mobile-responsive viewport configuration
